# 0925-DEV v2.6.6 运行覆盖补丁

## 目标

这份覆盖补丁修复了“分析很长但无用、方图与长图混淆、四图差异不足、模特权限错误、方案无法直接执行”五类问题。它只覆盖日常运行入口，不创建第二个插件、不改变 0925-dev 的插件身份。

## 唯一事实边界

1. 当前 Excel 的方图框内内容是最终展示事实源。
2. 指向方图的框外标注是执行说明，不自动变成广告文案。
3. 方图框外未指向方图的内容、长图主体和长图底部全部排除。
4. 截图先拆解出要展示的文字、组件、结构和效果；截图夹带的其他背景、残片和软件外壳不直接贴入。
5. 产品、Logo、正式文案、代言人身份/姿势/源图保持不变；普通模特只有当前 Excel 或框外标注要求时才可改变。
6. 方图底部文案、行序、分组、换行、字号比例、字色、位置、宽度比例、对齐和贴底关系固定；只允许改变文字框的外观皮肤和颜色，不能重排。
7. 参考图只影响 A 的非锁定视觉形式。B/C/D 必须有明显不同的场景、构图骨架、主体比例、视角、光线、材质、信息容器或色彩角色，不能只换色。
8. 四张是独立 1:1 成品；分析阶段不生成图片，生成阶段必须四次独立单画布调用。

## 分析阶段唯一可见输出

内部仍须完成工作簿、合并区、文本框、批注、绘图、嵌入媒体、截图和边界的逐对象读取与视觉核验；聊天只展示以下内容：

- 当前工单与类目框架；
- 方图框内全部正式文案，逐字保留换行、标点、数字和分组；
- 产品、Logo、代言人/模特、签名、截图和参考图的实际选用来源；
- 每条框外标注的“原文 → 目标对象/区域 → 执行动作”；
- 截图需保留、重建和排除的组件；
- 方图底部固定合同和长图底部排除说明；
- 锁定项、可变项和真正未解决项；
- 最后只给 READY_FOR_PLAN 或具体 BLOCKED_PARSE 原因。

不展示工作簿内部无关表格、解析日志、哈希清单、重复门禁清单、历史规则复述或营销推断。

## 方案阶段

用户确认后，自动选择对应的五套框架原文（保健营养、母婴、个护清洁、美妆护肤、食品营养食品）并逐字段填充当前事实。每套方案只包含：定位、构图、素材锁、文案锁、截图执行、底部锁、模特规则、场景/光影/材质、与其他方案的差异、可直接运行的单画布提示词和成品检查点。不得使用“同上”“按 Excel”“沿用前文”或框架示例补事实。

A 贴近参考图的设计形式；B/C/D 分别采用不同视觉系统。允许变化的是模特（仅在当前工单授权时）、非底部构图、背景、光线、材质、信息容器和视觉动线。禁止变化的是产品、Logo、正式文案、代言人身份姿势、截图有效结构和底部合同。

## 生图阶段

收到“开始生成”后，按 A、B、C、D 四次独立事务执行。每次绑定当前 Excel 的源图、COPY_LEDGER、SCREENSHOT_STRUCTURE_CONTRACT 和 BOTTOM_CONTRACT；只生成当前单张画布。先验收背景，再合成原素材和逐字文案，最后核对底部、截图、模特和差异。中间背景、模板、拼贴或四宫格均不得交付。
