# v2.6.0.1 代言人默认角落锚定修复

## 目的
在 2.6.0 稳定基线上补一项默认规则：若 Excel 未明确指定更大比例或非角落位置，代言人素材默认缩小并放置在画面左下角或右下角。

## 强制规则
- `ENDORSER_DEFAULT_CORNER_ANCHOR_ACTIVE=ACTIVE`
- `ENDORSER_SMALL_SCALE_DEFAULT_ACTIVE=ACTIVE`
- 若工单存在代言人素材，但 Excel 未给出更高优先级位置合同，则默认：
  - 代言人只允许位于左下角或右下角；
  - 代言人应为小比例辅助元素，不得成为主视觉主体；
  - 不得遮挡产品主包装、核心标题、价格区和关键卖点区；
  - 不得放大到与产品主体等权重或更高权重；
  - 不得置于画面中轴中心或大面积占位。
- 如 Excel / 方图截图 / 框外标注已明确要求人物位置，则仍按更高优先级事实执行。

## 四图执行
- A/B/C/D 可在左下角与右下角之间选择其一，但必须保持小比例且不遮挡主体；
- 若首次方案已冻结某一角位且当前工单要求“位置一致”，则四图保持同侧。

## 失败判定
出现以下任一情况，视为 FAIL：
1. 代言人居中或放大成主主体；
2. 代言人遮挡产品、Logo、标题、价格或底部合同主句；
3. 代言人被替换、换脸、换装、换姿势；
4. 代言人位置漂移到上方或中间主要视觉区域。
