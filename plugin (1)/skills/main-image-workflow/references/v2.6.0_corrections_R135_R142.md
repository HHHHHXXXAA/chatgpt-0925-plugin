# v2.6.0 Corrections R135–R142 — Append Only

- R135 源素材调用级绑定：产品/包装、Logo、代言人必须以当前Excel真实源图绑定到每一次A/B/C/D单图事务；文字描述不能替代源图引用。
- R136 禁止受保护素材生成式回退：执行路径无法保持真实源素材时必须BLOCKED_ASSET_HANDOFF/BLOCKED_COMPOSITOR，禁止生成近似产品、近似Logo或相似人物继续交付。
- R137 代言人位置绝对锁：建立ENDORSER_POSITION_CONTRACT，冻结侧别、角落/区域、相对坐标、相对尺寸、朝向和遮挡关系；A/B/C/D不得漂移、换边或镜像。
- R138 单方案单画布调用：每次图像调用只能包含一个ACTIVE_VARIANT、一个完整广告方案、一个1:1画布和一个输出目标；其他方案必须从该调用排除。
- R139 调用载荷审计：调用前ACTIVE_VARIANT_COUNT=1、FULL_AD_CONCEPT_COUNT=1、CANVAS_COUNT=1、OUTPUT_TARGET_COUNT=1、OTHER_VARIANTS_EXCLUDED=PASS，否则禁止调用。
- R140 展示前拼接阻断：任何四宫格/拼接/分屏/联系表/多面板/多画布/多个完整广告方案并列在展示前直接REJECTED_QA，不能裁切拆分计数。
- R141 产品/Logo/代言人后验身份核验：每张图必须通过PRODUCT_PIXEL_IDENTITY_CHECK、LOGO_IDENTITY_CHECK、ENDORSER_SOURCE_AND_ANCHOR_CHECK、ENDORSER_POSITION_CHECK后才可计数。
- R142 错误交付零容忍：受保护素材、人物位置或画布数量任一错误时宁可阻塞/重试当前图，不得以“整体效果可接受”放行。
