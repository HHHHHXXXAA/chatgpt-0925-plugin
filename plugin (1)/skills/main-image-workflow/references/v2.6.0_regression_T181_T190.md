# v2.6.0 Regression T181–T190 — Append Only

- T181 产品源图交接：每个A/B/C/D事务均绑定同一当前Excel产品/包装真实源对象；不得仅用产品名称/描述重建。
- T182 Logo源图交接：每个事务均绑定当前Excel原Logo源对象；任何近似Logo、重排字、改色、改比例均FAIL。
- T183 代言人源图交接：每个事务均绑定同一代言人原图；换人、换脸、换装、换姿势、镜像均FAIL。
- T184 代言人位置合同：同一工单A/B/C/D的代言人位置满足冻结的ENDORSER_POSITION_CONTRACT；换边、换角、明显漂移或比例变化均FAIL。
- T185 无源绑定阻塞：故意移除PRODUCT_SOURCE_REF/LOGO_SOURCE_REF/ENDORSER_SOURCE_REF之一，系统必须阻塞而不是生成相似替代。
- T186 单调用单方案：检查每一次图像调用上下文只有当前ACTIVE_VARIANT，不含其他三个完整方案或“生成四张/四个方案”等集合语言。
- T187 单调用单画布：每次调用目标CANVAS_COUNT=1、OUTPUT_TARGET_COUNT=1；不得一次请求多画布或多完整广告方案。
- T188 展示前拼接拒绝：故意返回四宫格/拼接/联系表/分屏结果，必须在展示前REJECTED_QA且FOUR_OUTPUT_COUNTER不增加。
- T189 本次失败案例回归：以“代言人被替换、代言人位置变化、产品/包装替换、Logo替换、四图拼接”为联合故障集，任一出现即FAIL。
- T190 综合执行闭环：四张均由真实源素材绑定的A→B→C→D独立事务生成/编辑，四张独立、无拼接、产品/Logo/代言人身份与位置全部正确，才DELIVERABLE。
