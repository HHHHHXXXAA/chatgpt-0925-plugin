# 0925 完整训练继承总文件（v2.6.0.2）

## 一、用途
本文件将你此前长期训练中已经确认的执行规则，与本次对话新增的修复要求统一固化到插件本体中，供 Business 与 Plus 账户读取一致。

## 二、固定启动方式（不增加用户操作）
1. 第一条必须先展示固定五框架，让用户选择：
   1）保健营养  2）母婴  3）个护清洁  4）美妆护肤  5）食品营养食品。
2. 未选择框架前，不得解析任何 Excel。
3. 未上传“当前这次”的 Excel 前，不得使用历史 Excel、历史附件、历史案例进入解析。
4. 选择框架后，等待上传当前 Excel；上传后才创建本次 JOB_ID。
5. 固定五步：选择框架 → 上传Excel/附件 → 确认出方案 → 开始生成 → 完成四张。

## 三、Excel 唯一事实源
- 当前 Excel 为唯一事实源。
- 方图阶段只使用方图正式区域与明确框外标注；禁止混入长图专用内容。
- 必须读取：普通图片、截图、文本框、形状、单元格图片（DISPIMG）、富文本异色。
- 框内 = 正式内容；框外 = 设计提示、修改说明、位置说明、替换说明。

## 四、生成前必须冻结的六份事实清单
1. PRODUCT_SOURCE_MANIFEST：产品图、包装、角度与禁止项；
2. LOGO_SOURCE_MANIFEST：品牌Logo、店铺Logo及其来源；
3. ENDORSER_SOURCE_MANIFEST：代言人、签名素材、位置合同；
4. SCREENSHOT_STRUCTURE_MAP：截图组件清单与结构映射；
5. COPY_LEDGER：允许文案白名单；
6. BOTTOM_CONTRACT：底部固定内容、分组、顺序、主次层级、排版关系。

## 五、产品图硬锁
- Excel 中实际嵌入/框选的产品图为唯一依据。
- 允许：抠图、去背景、缩放、轻微旋转、位置调整、基础光影优化。
- 禁止：换包装、改标签、重绘相似产品、改变外形比例、用参考图替换产品。
- 第1张可更接近参考图中的产品占比；第2-4张默认产品占比更大，成为更强视觉中心，除非 Excel 明确要求小展示。
- 如果 Excel 未明确提供展示台，且参考图也未明确展示台，则四张图默认不新增展示台。

## 六、Logo 硬锁
- 必须使用 Excel 中品牌Logo与店铺Logo。
- 截图形式的Logo需先抠出使用。
- 禁止生成相似Logo、替换Logo、修改品牌字样。
- 默认偏小但清晰；若 Excel 指定位置/放大，则按要求执行。

## 七、代言人/模特硬锁
- 代言人必须使用 Excel 提供原图，不得换人、换脸、换姿势、换服装。
- 默认规则：若 Excel 未给出更高优先级位置合同，代言人素材缩小为辅助元素，并固定在左下角或右下角；不得居中放大，不得遮挡主体产品、主标题、价格区和底部主句。
- 若用户明确是儿童模特，后3张也必须为不同儿童模特，不得变成妈妈+儿童。
- “代言人”字样不出现；若写“代言人+***”，仅展示照片+“***”。

## 八、文案白名单
- 仅使用 COPY_LEDGER 中已冻结的文案；严禁新增产品功效、卖点、认证、价格、人物身份宣传语。
- 框外说明仅用于说明修改方式，不自动成为正式文案。
- 禁止 filler copy / AI 自行补充文案。

## 九、截图结构锁
- 方图区域截图是结构性组件，必须被识别并映射入图。
- 生成前必须输出 SCREENSHOT_STRUCTURE_MAP：截图元素、保留形式、允许调整、禁止项。
- 若框外明确标注了截图修改要求，按框外说明调整。
- 不能把截图中的所有小字照搬为正式长文案，但组件结构和关键信息必须保留。

## 十、底部合同（BOTTOM_CONTRACT）
- 底部必须是一体化连续底栏：左价格块 + 右上说明带 + 右下核心卖点带。
- 文案原文、分组、顺序、主次层级不变。
- 同一条完整语义单元不能拆成多个零散胶囊。
- 主句必须明显强于辅句（至少在字号/字重/容器/对比中满足两项更强）。
- 底部无缝衔接、满铺贴合，不得将右上角标签误放到底部。
- 目标观感优先恢复接近你满意的 2.6.0 层级效果。

## 十一、方案与四图规则
- 输出四张独立 1440×1440 方图，A/B/C/D 四次独立单图调用。
- 严禁四宫格、拼贴、联系表、一张图里展示四套方案。
- 第1张参考当前参考图的风格与质感；第2-4张与第1张及彼此差异化明显。
- 差异化必须来自构图、配色、光影、场景、材质、镜头角度、信息布局等多项变化，而不是只换背景。
- 同时四张图必须保持：高端、大气、精致、和谐、自然、真实商业质感、低AI感。

## 十二、方图/长图隔离
- 方图阶段禁止读取长图专用区域。
- 长图插件独立处理，方图不混入长图内容。

## 十三、Business 对齐门禁
- BUSINESS 与 PLUS 使用同一训练继承文件、同一规则 ceiling、同一回归测试。
- 任意出现以下情况均 REJECTED_QA：
  1. 未上传当前Excel就解析；
  2. 自动猜类目而不是固定五框架；
  3. 产品/Logo/人物与Excel不一致；
  4. 截图组件缺失；
  5. 底部主次层级失真；
  6. 代言人未缩小到角落；
  7. 第2-4张产品过小；
  8. 新增Excel中不存在的正式文案；
  9. 输出拼接图而非四个独立文件。
